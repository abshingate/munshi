## One-time setup — Mac (or iPad)

1. Open the **App Store**, search for **"Windows App"** (by Microsoft, free)
   and install it.
2. Open Windows App → **+** → **Add PC**.
3. In **PC name**, type the computer address from the table → **Add**.
4. Double-click the new tile; enter your **username** and **password** when
   asked.
5. If a certificate question appears, choose **Continue** — this is the
   company's own private computer; the warning is normal and safe.

## One-time setup — Windows PC

1. Press **Start**, type **Remote Desktop Connection**, open it (built into
   Windows — nothing to install).
2. In **Computer**, type the computer address → **Connect**.
3. Enter your **username** and **password**. If a different saved user shows,
   click **More choices → Use a different account** first.
4. On the certificate warning, tick *"Don't ask me again"* and click **Yes**.

## Daily use

1. Connect — a full Windows desktop opens in a window.
2. Double-click **TallyPrime** on the desktop and select the company.
3. If Tally asks for a **Name of User**, use the Tally username given to you —
   every entry is recorded against your name in the audit trail.
4. Supporting documents live in **C:\TallyData\Documents**, organised by year
   and month.
5. When finished: close Tally, then **Start → (your name) → Sign out** —
   please sign out rather than just closing the window.

## Good to know

- **One person in Tally at a time** (single-user licence): if Tally says the
  licence is in use, someone else is inside — coordinate and retry.
- **Ten wrong passwords lock the account for 15 minutes.**
- Your account cannot install software or change settings — if something seems
  broken, don't try to fix it; contact the operator.
- Everything is backed up automatically every night.
- Keep work files under **C:\TallyData**, not on the desktop.

## If something doesn't work

| Problem | What to do |
|---|---|
| "Can't find the computer" | It's switched off — ask the operator to start it, wait 2–3 min, retry |
| "Your credentials did not work" | Retype carefully (case-sensitive); after 10 tries, wait 15 minutes |
| Tally licence unavailable | Someone else is in Tally — coordinate |
| Frozen window | Close and reconnect — your Tally work is safe |
